# ADR 009 Minimal telemetry with separate evidence storage

Status: Adopted in blueprint v0.1; implementation pending.

Date: 5 October 2026.

## Context

Observability is necessary for engineering and economics, but unrestricted traces can expose secrets or proprietary content.

## Decision

Store allowlisted operational metadata by default and protected evidence separately. Track correlation IDs, versions, decisions, counts, latency and measured usage without raw credentials, prompts, responses or headers in logs. Private evidence retention is explicit; external telemetry and public export default to disabled.

## Consequences

A complete trace means auditable decisions and provenance references, not hidden chain-of-thought or raw network capture. Some debugging requires controlled private evidence access. Missing cost fields are unknown, not zero.

## Verification criteria

- Scan normal and exception paths with synthetic canary secrets.
- Verify exported fixtures contain only synthetic content and approved metadata.
- Reconcile mission-level usage with stage records including retries and fan-out.

## Alternative considered

Default full HTTP, prompt and response logging; rejected due to data and credential exposure.
