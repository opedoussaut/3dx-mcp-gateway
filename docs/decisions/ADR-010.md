# ADR 010 Read only vertical slice before orchestration

Status: Adopted in blueprint v0.1; implementation pending.

Date: 5 October 2026.

## Context

A broad agent showcase would mask unresolved authentication and API support while increasing failure modes.

## Decision

Start with deterministic engineering search and item retrieval for a synthetic review-readiness mission. Build the offline harness without claiming live integration. Complete current contract verification and authorized runtime checks before the live milestone. Add structure, knowledge, providers, specialists and writes in separately gated phases.

## Consequences

The first demonstration can intentionally use zero model calls. Fixtures use original NOVA semantics and must be mapped to verified platform fields. Knowledge/process completeness is not required to validate the smallest useful engineering decision.

## Verification criteria

- Pass synthetic success, ambiguity, access-denial, incomplete-coverage and injection cases.
- Reproduce the expected engineering conclusion with the explanation model disabled.
- Label every run SYNTHETIC_OFFLINE or PRIVATE_LIVE and forbid simulated-live presentation.

## Alternative considered

Immediate full multi-agent implementation with placeholder live endpoints; rejected.
