# ADR 003 Replaceable reasoning providers

Status: Adopted in blueprint v0.1; implementation pending.

Date: 5 October 2026.

## Context

NOVA must compare intelligence mechanisms without binding the mission runtime to one vendor.

## Decision

Use a provider-neutral request/result contract and explicit capability metadata. Route credentials through a private provider broker, never tool arguments or prompts. Enforce data classification and egress policy before adaptation. Preserve native usage categories for accurate pricing.

## Consequences

Adapters may differ in structured outputs, tool calling and cancellation. Unsupported guarantees are errors, not silent downgrades. Model names, price schedules and deployment policies are versioned at implementation time.

## Verification criteria

- Run identical synthetic mission contracts through two permitted adapters.
- Reject providers unable to satisfy required output/privacy constraints.
- Verify keys are absent from provider-visible text, traces and sanitized errors.

## Alternative considered

One vendor SDK embedded throughout the core; rejected because it couples policy and business logic to one API.
