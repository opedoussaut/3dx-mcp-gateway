# ADR 006 Platform content remains untrusted

Status: Adopted in blueprint v0.1; implementation pending.

Date: 5 October 2026.

## Context

Retrieved engineering text may contain malicious instructions, confidential fields or irrelevant content.

## Decision

Treat retrieved text as evidence, never control instructions. Enforce capability and destination limits outside models; isolate parsing; groom and project permitted fields before model egress. Refuse instructions to switch users, export data or register tools when they originate from evidence.

## Consequences

Prompt-injection detection is not a complete defense. Some content must be quarantined or handled locally. Evidence provenance and missingness must survive grooming so filtering does not create false certainty.

## Verification criteria

- Embed synthetic injection text in each supported content field and verify no extra capability.
- Test oversized and malformed content against parsing limits.
- Verify sensitive-field exclusion and protected provenance mappings.

## Alternative considered

Trusting platform text because it was retrieved from an authenticated tenant; rejected.
