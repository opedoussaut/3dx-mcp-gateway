# ADR 007 Release specific public API admission

Status: Adopted in blueprint v0.1; implementation pending.

Date: 5 October 2026.

## Context

Public announcements and example code do not establish a full supported operation contract.

## Decision

Classify each operation as PUBLIC_SUPPORTED, PUBLIC_UNCLEAR, PRIVATE_OR_INTERNAL or UNKNOWN. Require official release/deployment-specific contract evidence before IMPLEMENTABLE status. Separate observed paths from executable paths. Never infer public support from a 200 response, internal link or browser traffic.

## Consequences

The initial registry enables no platform operations. Entitlement-gated documentation can describe public APIs; access and support classifications remain distinct. Upgrades require deprecation and schema review before expanding the admitted release range.

## Verification criteria

- Validate registry invariants and mandatory contract fields.
- Reject execution for unknown, unclear and internal classifications.
- Test contract mismatch and fail closed instead of guessing fields or paths.

## Alternative considered

Network discovery, undocumented fallback routes or automatic registry self-approval by an agent; rejected.
